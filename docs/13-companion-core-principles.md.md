# COMPANION — CORE PRINCIPLES (HYBRID MODEL)

These principles govern all Companion workflows.

1. Companion services are service-based, not result-based.
2. Pricing is hybrid:
   - PER_GAME (fixed price per game)
   - TIME_BASED (per minute / per hour)
3. No sexual services allowed.
4. Custom services require admin approval.
5. Chat exists only while session is ACTIVE.
6. Payments are escrow-based.
7. Refunds are rule-based, not emotional.
8. Tipping is allowed only after COMPLETED sessions.
9. Tips are split:
   - Companion receives 90%
   - Platform receives 10%
